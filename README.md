# SOSNOVKA RP — animated GitHub Pages build

## Что внутри
- обновлённый адаптивный интерфейс;
- плавное появление блоков при прокрутке;
- анимированные счётчики;
- световой cursor glow;
- progress bar прокрутки;
- анимации hero;
- мобильное меню;
- форум из 11 категорий;
- поиск и фильтр;
- просмотр тем;
- создание локальных тем через localStorage;
- модальные окна;
- reduced-motion режим для пользователей, отключивших анимации.

## Установка
Если GitHub Pages у тебя настроен на `main /docs`, замени содержимое своей папки `docs` файлами из этой папки.

Важно: GitHub Pages публикует статические HTML/CSS/JavaScript-файлы. Поэтому созданные через форму темы не становятся общими для всех посетителей — они сохраняются только в браузере текущего пользователя. Для общего форума с аккаунтами, ролями, БД и модерацией нужен отдельный backend.
